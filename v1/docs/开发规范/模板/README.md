# 开发规范模板

模板用于记录工程变更的事实、证据和未完成项。填写时使用实际命令、退出码、文件范围和环境信息；不确定内容必须标记为“待确认”，不得把占位符写成结论。

| 模板 | 适用场景 |
| --- | --- |
| [变更设计与验收清单](./变更设计与验收清单.md) | 功能开发、缺陷修复、重构、性能优化或升级迁移 |
| [代码审查报告](./代码审查报告.md) | 代码、提交、分支或 Pull Request 的只读审查 |
| [验证与交付报告](./验证与交付报告.md) | 汇总测试、质量门禁、契约、发布和残留风险 |

模板不替代项目的接口文档、迁移脚本、发布手册或安全流程；相关唯一文档仍需同步更新。
