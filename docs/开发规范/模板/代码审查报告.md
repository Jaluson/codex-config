## 4. 分类检查

- [ ] 正确性：主流程、错误、边界、并发、状态转换。
- [ ] 安全：认证、授权、输入、输出、注入、敏感数据、外部调用。
- [ ] 契约：API、数据库、消息、配置、序列化、错误和兼容性。
- [ ] 数据一致性：事务、异步、缓存、重试、幂等和迁移。
- [ ] 性能：查询、网络、线程、渲染、包体、内存和资源释放。
- [ ] 可测试性：测试覆盖、稳定性、替身边界和回归证据。
- [ ] 可维护性：职责、依赖方向、重复、文档和可观测性。
